# CodeAlpha Task 3 - Data Visualization

## Project Overview

This project was completed as part of the CodeAlpha Data Analytics Internship.

The objective of this task is to transform raw sales data into meaningful visualizations that make trends, comparisons, and relationships easier to understand.

## Dataset

The project uses a Superstore-style sales dataset containing 1,000 sales records.

The dataset contains the following fields:

- Order_ID
- Order_Date
- Region
- Segment
- Category
- Product
- Quantity
- Sales
- Profit

## Technologies Used

- Python
- Pandas
- Matplotlib
- Seaborn

## Visualizations Created

### 1. Sales by Category

Compares total sales across different product categories.

### 2. Sales by Region

Shows the total sales generated by each geographical region.

### 3. Profit by Category

Compares total profit across product categories.

### 4. Monthly Sales Trend

Shows how sales change over time on a monthly basis.

### 5. Sales vs Profit

Uses a scatter plot to examine the relationship between sales and profit.

### 6. Top 10 Products by Sales

Identifies the products generating the highest total sales.
